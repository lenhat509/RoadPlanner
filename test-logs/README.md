# Test logs

* `TEST_LOG.md` — history of every test run (one row per suite).
* `runs/<timestamp>.md` — report for a single run, including failing test names.
* `raw/<timestamp>/` — full console output and JUnit / `.xcresult` bundles (git-ignored;
  uploaded as CI artifacts).

Generated by `scripts/test-all.sh`; see `docs/TESTING.md`.
